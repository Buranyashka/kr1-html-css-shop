# kr1-html-css-shop

Учебный frontend-проект многостраничного сайта интернет-магазина.

## Контрольная работа №1

**Тема:** «HTML и CSS: разработка многостраничного сайта».

В проекте реализован многостраничный HTML/CSS-сайт интернет-магазина
с единой навигацией, семантической разметкой, формой заявки, формой
обратной связи, модальным окном, таблицей характеристик, Flex/Grid-раскладкой,
CSS-переменными, состояниями интерфейса и БЭМ-именованием классов.

## Реализованные элементы

### Семантика
- `header`, `nav`, `main`, `section`, `article`, `aside`, `footer`, `address`, `table`, `form`, `dialog`.

### Навигация
- единое меню между пятью страницами;
- активный пункт меню через модификатор `site-nav__link--active`;
- хлебные крошки на внутренних страницах;
- якорные ссылки: `#advantages`, `#popular`, `#contacts`.

### Карточки товаров
- блок `product-card` с модификатором `product-card--featured`;
- элементы: `product-card__title`, `product-card__description`, `product-card__price`, `product-card__button`;
- бейджи поверх карточек (`position: absolute`).

### Форма заявки (`order.html`)
- поля: имя, e-mail, телефон, тема заявки, комментарий;
- чекбокс согласия на обработку персональных данных;
- базовая HTML-валидация (`required`, `type="email"`);
- JS-обработка отправки и вывод сообщения об успехе.

### Форма обратной связи (`contacts.html`)
- поля: имя, e-mail, сообщение;
- JS-обработка отправки и сообщение об успехе.

### Модальное окно (`index.html`)
- реализовано через `<dialog>`;
- открывается кнопкой «Заказать» в карточке товара;
- содержит форму заявки с полями имя и e-mail;
- закрывается кнопкой «Закрыть» или клавишей Esc.

### Таблица
- таблица характеристик товара на странице `product.html`;
- `<caption>`, `<thead>`, `<tbody>`, `<th scope="col">`;
- сводная таблица товаров на странице `order.html`.

## CSS-архитектура

### CSS-переменные (`:root`)
- цвета: `--color-bg`, `--color-text`, `--color-primary`, `--color-border`, `--color-danger`, `--color-success` и др.;
- отступы: `--space-xs`, `--space-sm`, `--space-md`, `--space-lg`, `--space-xl`;
- скругления: `--radius-sm`, `--radius-md`, `--radius-lg`;
- ширина контейнера: `--container-width`.

### Состояния
- `:hover` для кнопок, ссылок и навигации;
- `:focus-visible` для доступности (видимый фокус);
- `:disabled` и модификатор `button--disabled`;
- `[aria-invalid="true"]` для ошибочных полей.

### Flexbox и Grid
- Flexbox: навигация, карточка товара, кнопки формы;
- CSS Grid: сетка карточек `products-grid`, каталог `catalog-layout`, контакты `contacts-grid`, страница товара `product-detail`.

### Позиционирование
- `position: sticky` — шапка сайта;
- `position: relative` — карточки товара и контактные карточки;
- `position: absolute` — бейджи «Хит», «24/7», «Ответ»;
- `z-index` — шапка (10), бейджи (2),.

## БЭМ-структура

В проекте используются следующие БЭМ-блоки:

- `site-header` — шапка сайта;
- `site-nav` — основная навигация;
- `breadcrumbs` — хлебные крошки;
- `hero` — первый экран главной страницы;
- `section` — универсальный раздел;
- `products-grid` — сетка товаров;
- `product-card` — карточка товара;
- `product-detail` — страница товара;
- `product-table` — таблица характеристик;
- `catalog-layout` — структура страницы каталога;
- `catalog-filters` — фильтры каталога;
- `order-dialog` — модальное окно заявки;
- `order-form` — форма заявки;
- `contacts-grid`, `contacts-card` — блок контактов;
- `button` — кнопка;
- `site-footer` — подвал сайта.

Именование элементов — через `block__element`, модификаторов — через
`block--modifier` или `block__element--modifier`.

## JavaScript

Файл `js/main.js`:

- открывает и закрывает модальное окно на `index.html`;
- передаёт выбранный товар в скрытое поле формы;
- валидирует формы на `order.html` и `contacts.html`;
- показывает сообщение об успешной отправке;
- безопасен для страниц без модального окна (не вызывает ошибок в консоли).

## Как проверить работу

- Пройти по меню между всеми пятью страницами.
- На `catalog.html` проверить сетку карточек и фильтры.
- На `product.html` — таблицу характеристик и бейдж «Хит».
- На `index.html` нажать «Заказать» — откроется модальное окно.
- На `order.html` — отправить форму и увидеть сообщение об успехе.
- На `contacts.html` — отправить форму обратной связи.
